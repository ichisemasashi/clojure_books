## 環境

- Clojure **1.12.x**（`deps.edn` は 1.12.1）
- 推奨 JDK **21**

## 通読版プロトタイプの実行

```bash
clojure -M:run    # 章デモ一括（展開前後）
clojure -M:test   # ケース A/B
clojure -M:verify # 調査時スイート
```

詳細は [プロトタイプ.md](./プロトタイプ.md)。  
通読版の本文は [原稿/](./原稿/)（執筆〜統合: [本文ドラフト.md](./本文ドラフト.md) → [編集レビュー.md](./編集レビュー.md) → [全体統合.md](./全体統合.md)）。各章は統合済 v0.3。通し読みは [原稿/通し原稿_通読版.md](./原稿/通し原稿_通読版.md)。
