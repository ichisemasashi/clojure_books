# 本文・企画文書のライセンス

本書の **本文・原稿・企画・ノート・レビュー記録**（`原稿/`、`notes/`、およびルートの各種 `.md` のうちコード以外）は、次のライセンスで提供する。

**[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/)**

要約（法的拘束力は公式条文が優先）:

- **表示（BY）:** 著作者表示を残すこと  
- **非営利（NC）:** 営利目的での再利用は不可（著作者自身の頒布・販売は妨げない）  
- **継承（SA）:** 改変した成果物は同じライセンスで公開すること  

サンプルコード（`src/` / `test/` / `exercises` / `answers` および同等のコード）は別途 **[MIT](./LICENSE)**。

商業出版や営利の二次利用を希望する場合は、著者に個別に連絡すること。
