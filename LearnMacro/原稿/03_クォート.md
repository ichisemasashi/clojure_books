## 3.1 動機

マクロの本体は、多くの場合 **テンプレート** でフォームを組み立てる。そのテンプレート言語がクォート族である。

## 3.2 `quote` / `'`

```clojure
'(+ 1 2)
;; => (+ 1 2)  ; 評価されないリスト
```

## 3.3 構文引用（syntax-quote） `` ` ``

```clojure
`(+ 1 2)
;; => (clojure.core/+ 1 2)  ; 名前が名前空間修飾される
```

修飾が付くことで、展開先でも意図した `+` を指しやすくなる。

## 3.4 アンクォート `~` とスプライシング `~@`

```clojure
(let [x 10
      ys [1 2 3]]
  `(+ ~x 2)    ; => (clojure.core/+ 10 2)
  `(+ ~@ys))   ; => (clojure.core/+ 1 2 3)
```

- `~` … テンプレート内に、評価結果を1個埋め込む（**アンクォート**）  
- `~@` … 列を親リストに繋ぎ込む（**スプライシング**）

標準用語は上表どおり。混同しやすいので「反引用」は使わない（[`用語統一表.md`](./用語統一表.md)）。

## 3.5 自動 gensym `foo#`（予告）

```clojure
`(let [a# 1] a#)
;; => (clojure.core/let [a__123__auto__ 1] a__123__auto__)
```

同一の構文引用内では同じ `a#` が同じシンボルになる。  
**安全に使う演習は第6章まで待つ。** ここでは「一意な名前が付く」ことだけ覚える。

## 3.6 よくある混乱

| 混同 | 実際 |
|------|------|
| `'` と `` ` `` は同じ | 修飾と `~` の可否が違う |
| `~` の外でも評価が止まる | `~` の中だけが「穴」 |

## 3.7 演習

1. **書く:** 局所 `x` とベクタ `ys` から `` `(str ~x ~@ys) `` 相当を作れ。  
2. **直す:** `~` と `~@` を取り違えたテンプレートを直せ。

## 3.8 まとめ — 関数でよいか？

すでに値が手元にあり、単に呼び出すだけならクォートは不要。  
**まだ評価したくない形をデータとして保持・変形する**とき、クォートが必要になる。
