# はじめに（編集済 v0.2）

**題名:** Clojure マクロを読み、書き、控える  
**副題:** 評価・衛生・DSL までを一冊で身につける教科書  
**次へ（通読版）:** [第1章](./01_イントロダクション.md)

本書は、Clojure のマクロを **読める・書ける・控えられる** ようになるための通読書である。  
「すごい構文」を集める本ではない。展開結果を見て保守し、関数やデータで足りるときはマクロを選ばない判断まで含める。

## 対象読者

Clojure の基本（関数・コレクション・名前空間・`if`/`let`/`fn`/`def`）を一通り使える人。

## 通読版の読み方

初版の「薄い一本」は次の順である。

1 → 2 → 3 → 4 → 5 → 6 → 7（抜粋）→ 8 → **13**（ケース A/B）→ 14

**第9–12章は通読版では飛ばす**（束縛の深掘り、コード生成、DSL、ツールは完全版）。番号が飛ぶのはそのためである。

サンプルコードはリポジトリで動く。

```bash
clojure -M:run
clojure -M:test
```

**対象環境:** Clojure **1.12.x**（サンプルは `deps.edn` の **1.12.1**）。推奨 JDK は **21**（検証実測は環境により異なる場合あり）。  
展開例に出てくる gensym 名（`temp__123__auto__` 等）は実行ごとに変わるので、形だけを追う。

用語は [`用語統一表.md`](./用語統一表.md) に従う。

## 本書の約束

1. `clojure.core` と、対比用の定番ライブラリ入口を、展開や設計境界付きで読める  
2. 制御構文・束縛・薄い糖衣を、衛生に配慮して書ける  
3. 「関数／データで足りる」と判断できる  

詳細な企画は `企画提案書.md`、目次の正本は `構成設計.md` を参照してほしい。
