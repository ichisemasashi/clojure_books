```bash

LEARNMACRO_BUILD_PDF=0 ./制作/build.sh
```

### PDF 依存（Homebrew）

```bash
brew install --cask font-noto-sans-cjk-jp font-jetbrains-mono
# 任意（コード用の代替）: brew install --cask font-noto-sans-mono
# エンジン: MacTeX / BasicTeX の xelatex（PATH に /Library/TeX/texbin）
```

## 4. 既知の制限

1. **PDF 組版:** pandoc → xelatex の簡易組版。商業入稿品質（版面・禁則の細かい調整）ではない。  
2. **EPUB / HTML 内リンク:** 章ファイルへの相対リンクはビルド時に `#chNN` へ置換（[`制作/rewrite_ebook_links.py`](./制作/rewrite_ebook_links.py)）。目次など通しに含まれない文書へのリンクはラベルのみになる。  
3. **表紙デザイン:** テキスト表紙。商業表紙は商業分岐で別途。  
4. **Noto Sans Mono（variable）:** fontspec が拾えない場合があるため、既定の等幅は JetBrains Mono。
