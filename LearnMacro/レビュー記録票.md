## 2. 総合所見（先に結論）

強みはある。**「読む／書く／控える」「展開前後」「関数対比」「通読版カット」** は教科書として戦える骨格だ。

ただし敵対的に見ると、いまのセットは次の欠陥を抱えたまま「工程1〜3完了」と宣言している。

1. **完了基準のすり替わり** — 「各章に核の当てがある」を、未検証のプレースホルダで充足したことにしている  
2. **約束と中身の不一致** — 企画の到達約束・成功指標が、通読版カットや未調査のライブラリ観察と噛み合わない  
3. **正本の分裂** — 記述範囲（版なし）と構成設計（v1.0）と企画の参照先がずれ、どちらを信じるか不明  
4. **未決のまま前に進む構造** — Clojure 版、公開形態、ライセンス、仮題の確定が工程4のブロッカーなのに未管理  

以下、指摘は **C（Critical）/ M（Major）/ m（Minor）/ O（Observation）** とする。  
**処置**は必須対応の提案。記録票自体は草案ではなくレビュー成果物とする（指摘の是非は別途決裁）。

## 3. 指摘一覧

### C-01 — 「調査完了」は完了基準を満たしていない

| 項目 | 内容 |
|------|------|
| 重大度 | Critical |
| 対象 | 調査素材、工程表（工程2完了） |
| 指摘 | 工程表の完了目安は「各章に核となる参照または例の当て」。調査素材§3の状態列はほぼ「草案／要精読／要観察／要調査」のまま。§2.4バックログと§4.3要検証は未着手。なのに工程2を「完了」、文書を「確定版」としている。**地図の承認**と**調査の完了**を混同している |
| リスク | プロトタイプで「核が無い／薄い」が発覚し、構成・約束の巻き戻しが起きる |
| 処置 | (a) 工程2を「方向確定・カタログv1」と再定義して進捗表記を直す、または (b) 章1–6とケースA/Bの核だけでも REPL検証済みにしてから「完了」を維持する。どちらか必須 |

### C-02 — 成功指標と通読版カットが矛盾する

| 項目 | 内容 |
|------|------|
| 重大度 | Critical |
| 対象 | 企画提案書§12、構成設計§2.3 |
| 指摘 | 成功指標は「章立てどおりに独習してケーススタディの半数以上を完走」。構成の通読版は章9–12を後回し、ケースはA+B必須（#3以降は厚くする段階）。**測る本と作る本が違う** |
| リスク | 薄い一本で満足して公開し、約束未達になる／逆に成功指標に引っ張られ通読版が死ぬ |
| 処置 | 成功指標を「通読版」「完全版」に分割して書き直す。または通読版に章12の最小（展開テスト）とケースCを必須に戻す |

### C-03 — 企画の約束①が内容・調査実態を超えている

| 項目 | 内容 |
|------|------|
| 重大度 | Critical |
| 対象 | 企画提案書§3 約束1、調査素材§2.3–2.4、構成設計 第11–12章 |
| 指摘 | 約束は「`clojure.core` **および定番ライブラリの入口**を展開付きで読み解ける」。一方で `core.async` は紹介止まり、Hiccup/HoneySQL/ルーティングは「要観察」、clj-kondoは「要確認」。**定番ライブラリを約束に入れた時点で調査未了のまま確定した** |
| リスク | 読者・版元から見て約束違反、またはDSL章が肥大化 |
| 処置 | 約束1を「`clojure.core` を中心に、対比用にデータ駆動APIを観察できる」へ縮小する。ライブラリ精読を約束に残すなら調査バックログを工程2の再開条件にする |

### C-04 — 正本（source of truth）が分裂している

| 項目 | 内容 |
|------|------|
| 重大度 | Critical |
| 対象 | 記述範囲、構成設計、企画提案書§6 |
| 指摘 | 企画§6は「詳細は記述範囲」と指すが、節レベル目次の正本は構成設計。記述範囲§5はケースを「2〜3本」、§8は「詳細アウトラインをこれから」と **完了済み作業を未着手扱い**。版番号もなく、確定プロセスの外に置かれたまま |
| リスク | 執筆者が古いTOC・本数・次ステップを信じたまま進む |
| 処置 | 記述範囲を「範囲地図（superseded by 構成設計 for TOC）」と明記して版付けするか、構成設計へ吸収して退役させる。企画§6の参照先を構成設計に切り替える |

## 4. 文書間矛盾マトリクス（要約）

| 論点 | Aの主張 | Bの主張 | 判定 |
|------|---------|---------|------|
| ケース本数 | 記述範囲「2〜3本」 | 企画・調査・構成「最大6／必須2–3」 | 記述範囲が古い |
| 詳細の正本 | 企画→記述範囲 | 実体→構成設計 | 参照切れ |
| 調査完了 | 工程表「完了」 | 調査内部「草案・要検証多数」 | 完了の意味が不実 |
| 読者成功の定義 | 企画§12 フル章立て | 構成§2.3 薄い一本 | 矛盾（C-02） |
| ライブラリ精読 | 企画約束に含む | 調査未了・構成は観察 | 過大約束（C-03） |
| 仮題 | §13 確定 | 見出しは仮題のまま | 手続不備（M-01） |
| core読解演習 | 毎Part | 構成で章により欠落 | 方針不一致（M-07） |
