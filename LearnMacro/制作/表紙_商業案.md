# 表紙案（商業・POD 用）

書籍名をヒーローに据えたテキスト表紙。商業イラストが入るまでの **レイアウト仕様** として使う。

## 表1（表紙）

```
┌─────────────────────────────────────┐
│                                     │
│   Clojure マクロを読み、書き、控える   │  ← 最大・最優先
│                                     │
│   評価・衛生・DSL までを一冊で         │
│   身につける教科書                   │
│                                     │
│   ─────────────────────────────────  │
│   読める・書ける・控えられる           │
│                                     │
│                         確定版 v1.0  │
└─────────────────────────────────────┘
```

- 背景: 単色ではなく、薄いグリッド／紙質テクスチャ可（紫グラデやクリーム＋テラコッタは避ける）  
- ブランド信号: 書名がナビより大きいこと（書名を外すと他書と区別できない配置にしない）  
- 第1面に載せないもの: 目次抜粋、統計、スケジュール、住所  

## 表4（裏表紙）

- 短い約束文（読む／書く／控える）  
- 対象: Clojure 1.12.x／推奨 JDK 21  
- リポジトリ URL  
- ISBN・定価（商業時）
