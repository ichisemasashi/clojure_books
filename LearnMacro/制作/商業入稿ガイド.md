## 1. 想定仕様（仮）

| 項目 | 仮値 | 備考 |
|------|------|------|
| 判型 | A5（148×210 mm） | 技術同人・技術書で多い |
| 本文マージン | 上下 18 mm／ノド 20 mm／小口 16 mm | 製本後にノドが足りるか確認 |
| 本文フォント | Noto Sans CJK JP（または版元指定の書体） | 等幅: JetBrains Mono / Source Han Mono |
| 本文組 | 横組・一段 | コードブロック多め |
| カラー | 本文モノクロ想定／表紙カラー可 | |
| ISBN / 発行者 | 未定 | 商業時に版元記入 |
| 本文ライセンス | CC BY-NC-SA 4.0（現状） | 商業契約で上書きする場合あり |

---

## 2. 入稿チェックリスト

- [ ] 確定版タグ（例: `v1.0.0`）と入稿 PDF のハッシュを記録  
- [ ] 表紙（表1）・裏表紙（表4）・背幅（ページ数確定後）  
- [ ] 奥付の発行者・発行日・ISBN・連絡先  
- [ ] トンボ／裁ち落とし（版元指定。自前 POD では不要なことあり）  
- [ ] フォント埋め込み確認（PDF プロパティ）  
- [ ] コードの行長がはみ出していないか（A5 で再確認）  
- [ ] 正誤表の最新版を別紙または巻末に同梱するか決定  
- [ ] サンプルコードの URL（GitHub）を奥付またははじめにに明記  

---

## 3. 印刷向けビルド

```bash
# A5 寄りマージンの PDF（pandoc + xelatex）
LEARNMACRO_PRINT_LAYOUT=1 ./制作/build.sh
```

生成物は通常どおり `dist/book-*.pdf`。商業最終は版元の InDesign／LaTeX テンプレに流し直す想定。

## 4. 権利・契約の注意

| 対象 | 現状 | 商業時 |
|------|------|--------|
| コード | MIT | そのまま再利用しやすい |
| 本文 | CC BY-NC-SA 4.0 | 版元独占などが必要なら **別契約で再許諾** |
| 引用 | 要約・独自再構成 | 長文 verbatim は避ける（調査素材の方針） |
