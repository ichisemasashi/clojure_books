
### マップ

コレクションでやりたいことのもう1つは、それぞれの要素に対して関数を評価することで、コレクションを変換することである。例えば、数字のコレクションがあり、すべての数字を2倍にしたコレクションが欲しいとします。Clojure はあなたに選択肢を提供します。

1 番目のドアの後ろには `map` がある。`map`関数は関数とコレクションを受け取り、元のコレクションの各メンバーに関数を適用して作成したシーケンスを返す。いくつかの数字から始めるとすると

```clojure
(def some-numbers [1, 53, 811])
```

それを2倍にしたいのなら、こう書けばいい：
  
```clojure
(def doubled (map #(* 2 %) some-numbers))
```

あるいは、もし私たちが本のマップのコレクションを持っていて、タイトルだけが欲しかったら、こうすることもできる：

```clojure
(map (fn [book] (:title book)) books)
```

結果はこうなる：

```clojure
("Deep Six" "Dracula" "Emma" "2001")
```

実は、ここで近道をすることができる。マップで自分自身を検索する場合、キーワードは関数であることを覚えておいてほしい。つまり、最後の例では`fn`は必要なく、`map`に入力する関数として`:title`を使えばいいのだ：


```clojure
;; Turn the collection of books into a collection of titles.
;; The easy way!
(map :title books)
```

しかし、もし本のタイトルの "長さ "のコレクション（`(8 7 4 4)`）が欲しかったら、また`fn`が必要になるだろう：

```clojure
(map (fn [book] (count (:title book))) books)
```

しかし、よりクリーンな方法は、マッピング関数をさらに別の関数生成関数 `comp` で構築することだろう。`comp`関数は任意の数の関数を受け取り、入力された関数を順番に適用する関数を返す。例えば、`(comp str inc)`とすると、数値をインクリメントしてその結果を文字列に変換する関数が得られる。つまり、本のタイトルを生成するコードを以下のようにすることができる：

```clojure
(map (comp count :title) books)
```

2 番目のドアの向こうには、マップ関数のあまり知られていないいとこ、`for` がある。表面的には、`for`は伝統的な言語に見られるループのように見える。 以下は、例えば、タイトルの長さのコードを`for`で置き換えたものだ：

```clojure
(for [b books]
  (count (:title b)))
```


古いループのように、for は `books` コレクションの各値を順番に `b` にセットし、ボディ内の式を実行する。しかし、似ているのはここまでで、`map`と同じように、`for`は古いものから新しいシーケンスを構築する。優れた関数市民のように、`for`は値、この場合はすべてのタイトルの長さのシーケンスを生成する。
